# Информационная система учета технических средств

Данный проект представляет собой программный комплекс для автоматизации процессов учета технических средств (компьютеров, ноутбуков, МФУ, сетевого оборудования) в IT-отделе организации. 

Система имеет два независимых интерфейса для взаимодействия с единой базой данных:
1. **Веб-приложение** (основной интерфейс).
2. **Консольное приложение (CLI)** (альтернативный интерфейс для работы без браузера).

## Основные возможности
- Централизованное хранение данных об оборудовании (инвентарные номера, статусы, местоположение).
- Учет материально-ответственных лиц (МОЛ) и истории перемещений.
- Учет ремонтов, лицензий на ПО и дат профилактики.
- Учет расходных материалов (картриджи, бумага) с контролем остатков.
- Генерация и печать QR-кодов для быстрой идентификации оборудования.
- Аналитический дашборд с графиками и 6 рейтингами (часто ломается, старое, требует профилактики и т.д.).
- Экспорт данных в формат Excel.

## Технологический стек
- Язык программирования: Python 3.11
- Веб-фреймворк: Flask
- База данных: SQLite (встроенная)
- Фронтенд: HTML5, CSS3, Bootstrap 5, Chart.js
- Дополнительные библиотеки: qrcode, Pillow, openpyxl

## Инструкция по запуску

Для работы с проектом вам потребуется установленный Python версии 3.9 или выше.

1. Склонируйте репозиторий или скачайте архив с проектом.
2. Откройте терминал (командную строку) в папке с проектом.
3. Установите необходимые зависимости:
   pip install -r requirements.txt

### Запуск веб-версии (основной интерфейс)
4. Запустите сервер:
   python app.py
5. Откройте браузер и перейдите по адресу: http://127.0.0.1:5000

### Запуск консольной версии (CLI)
Если вы хотите работать с системой через командную строку, запустите:
   python main.py

*Примечание: обе версии программы (и веб, и консольная) используют один и тот же файл базы данных `equipment.db` и общий модуль бизнес-логики `database.py`.*

## Структура проекта
- `app.py` — главный файл веб-приложения (маршрутизация Flask).
- `main.py` — консольная версия приложения (текстовое меню).

- `templates/` — HTML-шаблоны для веб-интерфейса.
